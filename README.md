# POKEMON API
## Проект для отработки API, SQL и анализа/очистки данных
## Используемые библиотеки:
psycopg
python-dotenv
requests
pandas
matplotlib
fastapi
pydantic
uvicorn
## Как запустить: 
 - установить PostgreSQL и создать базу Pokemon с таблицей;
 - создать файл .env со строкой DB_PASSWORD='пароль от вашей БД';
 - один раз запустить `py db.py`, чтобы загрузить покемонов;
 - командой `py -m uvicorn main:app --reload` запустить локальный сервер и, по необходимости через адрес /docs изучить документацию/проверить работу эндпоинтов.
## Список Эндпоинтов: 
- *GET* /pokemon/{name}: один покемон по имени (200 или 404).
- *GET* /pokemon/type/{type}: все покемоны типа, по основному и дополнительному, отсортированы по id (200 или 404).
- *GET* /pokemon/top/{stat}: топ-10 по одному из шести статов, по убыванию (200 или 400).
- *POST* /pokemon: создать покемона из тела запроса (201, 409, 422).
- *PUT* /pokemon/{name}: заменить данные покемона целиком, id не меняется (200, 404, 422).
- *DELETE* /pokemon/{name}: удалить покемона по имени (200 или 404).
