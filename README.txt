1) Проект для отработки API, SQL и анализа/отчистки данных
2)Используемые библиотеки:
psycopg
python-dotenv
requests
pandas
matplotlib
fastapi
pydantic
uvicorn
3) Как запустить: pip install -r requirements.txt, в файле .env прописано скрытый пароль, команда uvicorn спользуется для поднятия локального сервера.
4)GET /pokemon/{name}: один покемон по имени (200 или 404).
GET /pokemon/type/{type}: все покемоны типа, по основному и дополнительному, отсортированы по id (200 или 404).
GET /pokemon/top/{stat}: топ-10 по одному из шести статов, по убыванию (200 или 400).
POST /pokemon: создать покемона из тела запроса (200 или 201, 409, 422).
PUT /pokemon/{name}: заменить данные покемона целиком, id не меняется (200, 404, 422).
DELETE /pokemon/{name}: удалить покемона по имени (200 или 404).
